# 页面、功能与详细测试共用规范

- 状态：评审中；统一原则已批准，页面参数供实现评审
- 依据：[架构](../02-system-architecture.md)、[治理](../03-engineering-governance.md)、[本轮规格](../superpowers/specs/2026-10-23-module-page-function-test-design.md)
- 使用 Skill：product-ui-taste、Frontloom Core FE/Vue、testing。项目安全不变量优先于通用 UI 建议。
- 已签核业务/参数以[WES-RULES-1.0](05-approved-rules-and-defaults.md)为准；B为定案、P为可测初始值、H为缺证据阻断控制，不将整套页面或测试标为已验收。

## 1. 页面阅读与布局

产品阅读：这是面向仓储操作员、调度员和受权维护员的高频表格/地图/详情工具；数据量由上线容量评审给出，未测前不宣称特定规模可用；库存和物理控制操作属高后果行为。Web/Simulator 沿用 Element Plus，PDA 沿用 UniApp 原生组件语义。

| 页面类型 | DENSITY / DATA_COMPLEXITY / CONSEQUENCE | 文本骨架和滚动 |
|---|---|---|
| L：列表/详情 | 3 / 2 / 2；危险写操作为 3 | 顶栏56 + 导航240/64；标题/过滤；表格；分页；右详情360–420。表格自身滚动，详情独立纵向滚动 |
| F：编辑/审批 | 2 / 2 / 3 | 标题/版本；主表单；关联只读证据；底部保存/取消。长表单一个纵向内容滚动，保存失败保留输入 |
| M：地图工作台 | 3 / 3 / 3 | 顶栏/范围；地图及图层；右对象详情；下方问题/未定位队列。地图平移不等于页面滚动 |
| W：部署/分步操作 | 2 / 2 / 3 | 环境/目标；步骤；差异/校验；复核；执行阶段与结果。离开页面后可按操作记录恢复 |
| O：只读诊断 | 3 / 3 / 1 | 状态/时间；过滤；时间线/记录；证据详情。无直接业务写入口 |
| P：PDA | 1 / 1 / 3 | 环境/联网/身份；当前任务；单一扫码焦点；数量/单位；确认区；回执。单列，输入/按钮触控目标≥44px |

Web 表格行高初始40px，可切换紧凑/标准/舒适；触控区不能随紧凑模式缩到44px以下。宽度≥1280px可并列详情，1024–1279px折叠导航，<1024px详情叠层/独立路由；<768px不承诺完整工程编辑，提供只读查看和授权的窄屏适配操作。PDA不使用桌面宽表格。

所有预算用 token 实现，字体放大200%、长标识和翻译扩展后仍能操作。对照支持中文/英文，并使用+40%伪本地化压力数据；日文资源沿用基线，RTL未纳入首期验收，不默认为支持。

## 2. 数据与操作约定

密集页面的列显隐/顺序/宽度/固定、个人视图、关联显示、远程/级联筛选、编辑回填和主从明细遵循[密集交互补充合同](03-dense-page-interaction-contract.md)。各模块末尾逐页矩阵限定默认/必显/可选列及依赖链；新增DTC-UI-013..032与本文件001..012共同使用，不把所有页面强制变成Grid。

- 每页的入口是拟议客户端路由，不代表现有 API；页面表给出全部必需字段，通用资源版本为只读不透明值，不能转为客户端自增数。
- 所有列表默认“更新时间降序、稳定ID升序”，流水/执行时间线“发生时间升序、稳定ID升序”；授权后分页，默认25、可选25/50/100。稳定tie-break只保证静态集合，实时跨offset请求不承诺无丢重。WMS库存核对/流水/盘点快照、Route基准对比及既有导出用RULE-25固定水位快照（10分钟），绑定主体/权限版本/条件/排序；到期/撤权失效，不用只加keyset游标伪装固定数据集。
- 精确业务标识查询与模糊名称搜索区分；仅批准的非敏感结构化过滤进入URL，其余仅在当前内存，刷新不持久恢复敏感自由文本。返回保留合法查询上下文。过滤变化回第一页；跨页选择以稳定ID集合保存，显示总数与当前筛选隐藏数；作用域改变清空并提示。无明确批处理规格的页面不提供批量控制。
- 数量使用十进制定点语义，精度/单位来自 WMS 物料单位策略；不能 JS 浮点随意四舍五入。坐标/时间/金额等不互用精度。
- 时间存储 UTC，显示现场时区与偏移；区间统一写清闭开边界。设备观测时间与服务端接收时间分别展示。
- `Unknown`、`Stale`、`NotApplicable`、无权限不可见与零值分开；库存0不等于未知库存，设备未回读不等于停止。
- 状态来自 owner query；推送仅触发版本化增量/回查。旧版本不能覆盖新状态，重连先查快照再处理增量。
- 所有写入带资源 ID、期望版本、作用域、幂等键/命令ID；同键不同摘要拒绝，同键同请求查首次结果。API 具体地址和错误码由后续契约评审锁定。
- 按钮前提可以明确禁用并给出键盘可达原因；永远不自动提权、切生产、解联锁或清预约。客户端禁用不替代服务端校验。
- 表单 blur/submit 校验；提交时聚焦错误摘要/首错，失败不清空。密码/权限/库存/设备/部署不能自动保存。
- 高风险确认展示目标环境、资源、影响、理由、所需审批；默认焦点为取消。安全PLC不是可通过软件覆盖的校验项。
- 提交返回 Accepted/处理中时显示操作记录，不宣称完成。结果未知先查操作和物理状态；不是简单“再次提交”。

## 3. 所有页面的状态合同

| 键 | 页面/区域行为 | 写入合同 |
|---|---|---|
| loading | 首次请求约1秒后用同形骨架；此前不闪烁；持续等待给阶段/耗时和重试/取消查询 | 未获得必需前提不允许写 |
| refresh | 保留旧内容和最后确认时间，明确更新中 | 控制前必须重新验证 freshness |
| first-empty | 解释数据来源，有创建权限且确有创建用例时才提供入口 | 不用演示数据假装真实 |
| filtered-empty | 保留过滤条件并提供清除过滤 | 不解释为系统没有数据 |
| zero-work | 明确“当前无待处理”，不是新手创建引导 | 无隐式副作用 |
| error/partial | 原因、建议动作、关联ID；局部失败仅影响该区；失效数据标记 | 缺失关键前提时拒绝相关写 |
| denied/read-only | 无权资源不泄露；受权只读用静态值与说明 | 直调服务端也拒绝 |
| stale/offline | 持续横幅、观测时间、受影响对象；未定位队列保留 | 不保存/排队/重放离线写；恢复后重新核验 |

只读页的“写入状态”不适用，仍测试直调拒绝。无表单页的字段校验不适用；无过滤页的 filtered-empty 不适用。每个模块必须给出逐页适用矩阵，不能把“不适用”省略。

## 4. 功能与详细测试记录

功能定义用表格记录 ID、页面、SCOPE/REQ、步骤/状态/拒绝与契约。表格后的事务说明是同一功能的规范，不是可选补充。每个新字段说明来源 owner，内部执行状态不擅自改成外部业务状态。

详细用例表每行是可执行测试记录。公共测试基线：

- 时间 `T0=2026-10-23T08:00:00Z`；使用受控时钟，阈值取批准的环境配置，不以示例作为生产默认。
- 租户TA/TB、仓库WA/WB，用户U1（TA业务权限）、U2（TA只读）、U3（TB）；模块另给角色和资源数据。
- 每个参数化变体从同一隔离基线重新开始，不能沿用前变体副作用。
- 默认 P1；库存/物理/授权/fencing/部署安全拒绝为P0。表中 B=真实Provider的API/持久化集成，E=页面E2E，C=Adapter契约，U=纯逻辑，S=确定性仿真，H=批准的现场验证。需要 H 的场景未联调前为 blocked，不以 S 代替。
- B逐 SQL Server/PostgreSQL/MySQL运行；C逐已批准Adapter/协议版本；PDA E逐实际支持的UniApp端与扫码终端。读取页面的E可用受控API测试状态，但不能代替B的事务证明。
- 清理C0：隔离数据库/测试租户及虚拟设备恢复快照，停止测试publisher/job，撤销测试会话，恢复时钟/网络注入。生产现场不按测试清理方式删数据。
- 涉及设备的清理C1：先停止注入并确认无在途物理动作，按批准现场手册恢复安全状态；未核验前保留保护，不清空活跃预约。随后才能执行隔离环境C0。
- 证据：初始快照、操作ID、响应/错误、最终owner查询、审计/账本/Outbox/命令计数与安全脱敏日志；不能只留HTTP成功码截图。

## 6. 实现交接与参数阻断

业务枚举/数量/流程、双人审批、常规缓存/重试/保留及容量目标已经[规则基线](05-approved-rules-and-defaults.md)批准，采用其P值并标默认来源；非法配置不回退。设备freshness/制动/几何/容量/能力、真实Provider/终端及正式runbook属于H，默认Unconfigured且阻断依赖控制，不能用PAR-10非安全投影目标代替设备门限。纯只读/草稿可先行，生产证据仍必需。

本规范没有创建通用CRUD生成器；共享仅限真正重复的表格/错误/权限/状态呈现与测试夹具。
