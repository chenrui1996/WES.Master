## 2. 表格列合同

### 2.1 工具栏与配置面板

```text
标题 / 当前范围 / 最后确认时间
个人视图 [默认] [保存视图] [另存为] [恢复视图]
搜索 [业务码] 结构化筛选 [仓/状态/时间] [查询] [重置筛选]
已生效条件 [仓WA ×] [状态待处理 ×]       [列设置] [显示密度]
表头：主标识 | 业务状态 | 关联对象 | 数量/单位 | 更新时间 | 操作
分页 / 已选N（含隐藏于当前筛选的M） / 当前页或全结果的明确范围
列设置：搜索列名 / 勾选 / 上移下移或拖动 / 宽度 / 固定位置
        [应用] [取消] [恢复默认列]     重要列标“必显”及原因
```

1. 字段以稳定`columnId`标识；翻译label、视觉序号、数据库列名均不能充当ID。每个子表有独立`tableId`，不与主表共用偏好。
2. 必显字段在各模块矩阵以`!`标识：主业务标识、决定当前动作的状态/质量/环境，以及操作所需精确数量/单位。必显不是权限豁免：无权字段根本不返回/不注册；缺少授权必需信息则阻断动作而非显示泄露内容。
3. 显隐只作用于授权的可选展示字段；至少一个主标识始终可见。取消只丢弃配置草稿；应用即时改变本次展示。默认视图下应用尝试保存个人当前列偏好；命名视图下只更新未保存工作副本，须点“保存视图”才覆盖该视图。业务写次数必须为0。
4. 列顺序只改变布局，不改变服务端行排序、业务优先级、流程步骤或任务派发顺序。支持拖动和键盘“上移/下移”，不能只有拖动。
5. 支持列宽调整与恢复默认；基准身份/名称列200px（最小160）、状态120（最小100）、数值120（最小100）、时间200（最小180）、说明240（最小180），最大600。使用token，长内容完整查看与200%字体优先于固定行高；不把示例宽度当禁止内容换行的约束。
6. 默认左固定首个主标识；有明确操作的表右固定操作列，其按钮权限独立控制；其余列可在左/中/右区域内重排。固定列宽合计超过表格容器一半时取消可选固定列；仍不足则中性提示并转详情查看，不能遮住全部滚动区。选择列非业务列，只有获批选择用例才出现。
7. 日期、枚举、数量右对齐/精确值、空值语义、只读列样式沿用共用标准。不能用隐藏列实现密级控制；CSV/导出不能由当前隐藏状态推导授权。

### 2.2 偏好持久化与升级

本轮采用本机当前浏览器的个人偏好，不承诺跨设备同步、团队共享或服务端偏好API。键包含environment、不可读主体标识、tenant、pageId、tableId；同一用户不同仓可共用纯布局，但仓/Pack等数据范围不得从缓存自动恢复授权。偏好仅存列ID/顺序/宽度/固定区/密度/视图定义，不存行值、名称快照、凭据或待写表单。

- 应用时以当前授权column schema规范化：去重/移除未知与已撤权字段，必显强制恢复，新增列按新schema默认加入；仅重命名label不重置布局。排序/筛选字段同样白名单处理。
- 保存`schemaVersion`与偏好格式版本；无法迁移/JSON损坏/存储满或禁用时提示“配置未保存/已恢复默认”，保留本次可用布局，不能假显示“已保存”。这不是业务失败，不触发业务重试。
- 登出清除内存行数据/选择/最近关联缓存；本机偏好只在匹配主体作用域读取。清理浏览器数据后回默认；多标签最后一次成功应用的个人偏好生效，其他标签提示有新设置、不覆盖未应用草稿；不承诺服务器级并发。
- “恢复默认列”只重置当前子表列配置；“重置筛选”只清非锁定条件；“恢复视图”恢复上次明确保存的视图。三者按钮不同，不混成“重置全部”。

## 3. 关联列、字典与跳转

| 类型 | 展示与查询合同 | 不能做的事 |
|---|---|---|
| 枚举/字典 | 稳定code随数据返回，label按当前语言解析；0/false有效，多选用有序ID集合。未知code显示“未识别值”及授权可见code并阻断依赖此值的写 | 按翻译文本保存状态、逗号拼接名称当ID、格式化时修改row |
| 主数据关联 | `reference={owner,type,id}`与授权displayCode/name/状态/版本分开；默认“业务码 · 名称”，同名可区分；受权详情跳转保留来源 | 前端任意join表/配置SQL；所有名称都点一次远程请求 |
| 历史事实 | 业务记录的历史名称/单位快照与当前主数据分区；详情显示快照时间/引用版本，当前改名不重写历史 | 新名称无标记覆盖当时审计/数量单位 |
| 缺失/无权/失败 | 当前作用域可知的缺失标“关联不可用”；无权统一受限提示，不回显隐藏名称/存在性；关联接口失败局部错误/重试 | 失败显示空白、ID冒充名称、错用其他租户同ID、全页判空 |
| 状态/链路关联 | 单据→行→运输→Leg→Pack任务→command/反馈→流水/问题按owner受权查询；全部回链携安全上下文 | 从关联展示直接改另一owner状态；供应商原始DTO/密钥进入普通列 |

列表query由owner提供授权投影或有界批量resolve契约；每批最多100个唯一引用、按owner分组，首屏缺省只解析当前可见行与明确选择的详情。服务端同样验证tenant/仓与字段权限；100是设计批大小而非性能SLO，容量评审可收紧。缓存键包括环境/主体/租户/owner/type/id/语言/权限版本，撤权或切上下文失效；不缓存未授权名称。按关联名称排序/筛选必须由允许该字段的owner服务端实现，不支持则说明不支持，不在当前页伪排序。

## 4. 新增、编辑与关联选择

### 4.1 选择器统一行为

- 远程选择器显示代码/名称/范围/可选状态，默认25条分页；精确业务码与名称搜索分开，长列表不预拉全租户。多选显示数量与可移除项，可展开完整清单，不仅显示第一个名称。
- 250ms去抖只用于查询；新请求取消旧请求并用request sequence、主体/tenant/父ID指纹校验回包。即使网络取消无效，旧回包也不得覆盖新列表或选值。加载/无符合项/无权限/接口错误有不同提示。
- 只接受owner返回且属于当前父范围的ID；不默认选第一项，不允许自由创建不存在的仓/物料/角色/点位。唯一候选也需显式选择，业务固定关系例外显示为只读绑定。
- 提交再次在服务端校验引用存在、启用/授权、父子归属、能力、版本及占用；候选列表不是资源预留或最终安全授权。

### 4.2 上下游依赖合同

1. 模块矩阵中`A→B→C`表示B/C的候选请求受已选父值限制，不代表自动选值或自动执行业务。父缺失时显示“先选A”，下游不能提交。
2. 用户变更父值，立即使旧下游选择不可提交；清空候选/下游引用及其派生名称，取消旧请求，再拉新范围。仅当owner证明旧引用仍有效时才允许用户明确保留；不能因显示名相同保留旧ID。
3. 如果影响已编辑明细，先预览受影响行数/字段，选择确认清除或取消父变更；取消保留原表单。不能默默丢行、沿用无效数量/单位、清理无关描述字段。
4. 编辑回填先读实体及版本，再用已保存ID批量解析当前引用；不依赖第一页候选碰巧含选项。禁用/已删除/无权关联不可用于新增；编辑历史显示受权事实并标不可新选。保持历史引用是否允许保存由模块状态/owner决定，不能自动替换首项。
5. 新增可继承显式当前仓/父节点/选中单据行，显示“来自当前范围”，服务端重验；多仓/多Pack/模糊筛选不推断唯一值。列表状态、复杂OR筛选、时间范围不是新单默认状态。
6. 新增与编辑入口独立：系统ID/状态/版本/审批/已执行事实只读；复制仅既有批准的草稿或新版本用例允许，重新分配业务身份，不复制密钥、授权审批、grant、command或终态。

## 5. 主从明细、选择与结果

- 主单与行有稳定ID（未保存行仅内存clientRowId）；排序/删除其他行后，关联回包仍按行ID+父指纹匹配，不能按数组index赋值。新增/编辑明细不是任意表格单元格自动保存。
- 上游单据→可操作行→容器/位置→数量/单位→动作，显示来源单号/行号及剩余。候选数量为查询快照；审核/收发仍由WMS原子检查。聚合不能把不同物料/单位/币种混加，不因选中行变少就当作整单量。
- 未提交在线输入遇到切主单/关闭/返回：显示保留当前编辑或放弃的明确选择；不自动创建本地草稿/离线队列。身份/租户切换及失效按安全规范清除，不把凭据和待写数据留给下一用户。
- 当前页全选与跨页选择分开；无获批批处理用例不提供“全部结果批量执行”。筛选/排序变化保留授权ID并显示隐藏选择数，换主体/租户/仓/Pack清选择。后台删除/撤权项移除并解释；执行前重验全部目标。
- 批处理仅适用于原模块已批准动作，每项显示成功/拒绝/未知与operationID；是否原子按owner原合同，不自创跨模块ACID。审批/强完/模式/部署等不能通过多选或分组拖动绕过逐项前提。
- 汇总注明“当前页/已选/全部匹配结果”、单位、授权过滤与计算时间；全部匹配结果由服务端计算，失败标不可用而非0。没有可比单位时不提供总量。
- 只有原设计已经允许导出的页面保留导出：列范围与数据范围分别确认，默认当前可见授权列；隐藏的可选列需显式选择，无权列不可选。服务端使用同一过滤/排序/权限重新校验，输出精确值与安全转义；下载再次授权、短期引用。未立项页面不因本节增加导入/导出按钮。

## 6. GitHub式密集操作的采用边界

采用清晰的个人视图标签、条件chips、列设置、行详情检查器、未保存视图标记，以及明确保存/另存为/恢复。每个视图仅含当前page/table的布局、允许的排序和非敏感结构化条件；名称租户内当前用户本机唯一，默认内置视图不可删除，可复制为个人视图。默认视图的“保存视图”要求命名另存，不改内置条件；默认列偏好独立于命名视图。命名视图的未保存工作副本只在内存，刷新/恢复回上次保存版本，切视图时明确提示放弃未保存设置；不把工作副本偷存为已保存视图。删除个人视图安全确认后回默认，不删除业务记录。

保存列出将持久化的条件；账号/手机号/自由文本业务码、密钥、临时签名、行选择、待审批对象/命令ID不进入持久视图或URL。普通查询筛选仅允许批准的非敏感字段进入URL，其余只在当前内存；“分享链接”仍按接收者权限查询，不包含个人布局或凭据。个人视图不带共享/邀请/团队默认功能。

分组仅对模块明确列出的低基数枚举/类别可用，由服务端对全授权结果分组计数/分页；不能把当前页组当全量。未知组单列，收起组仍显示问题数量；客户端不能因分组重排改变真实优先级/状态。没列分组字段的页面不提供通用任意分组。行拖动、跨组移动、内联改运行状态均不采用。复杂筛选不引入GitHub完整查询DSL，用类型化条件即可。

已签核[规则基线RULE-25](05-approved-rules-and-defaults.md)补充时间语义：实时页的分组/计数标各自查询时间与水位，更新中不能宣称跨页固定完整；核对/已有导出使用绑定主体/权限/条件/排序的固定水位快照、10分钟到期。keyset仅解决遍历方式，不自动提供固定集合；撤权使快照失效。冻结本地显示顺序不冻结owner，仍重新核验提交。

运行列表后台更新不使键盘焦点或所选行跳到其他对象；有动作确认/编辑时冻结本地呈现顺序并提示新数据可刷新，提交仍读最新owner前提。地图画布不套表格列配置，只有队列表格使用；PDA不套桌面Grid/多列拖动。

## 9. 实施门禁与Skill冲突处理

复用Vue组件/组合式逻辑不等于恢复元数据生成CRUD。列schema与依赖链必须为具名页面手写的类型化契约，任意反射数据库列/任意脚本关联/任意远程URL均不允许。请求取消、稳定行ID、字段权限投影在UI组件与owner接口分别验收，不只测试视觉截图。

通用Skill的自动满足前提、离线排队、乐观物理成功、跨组拖动改状态不适用；必需安全条件不足继续明确阻断。长操作工作量未知保留阶段/耗时，不造百分比。横滚仅限表格容器。桌面菜单/列可用可达的禁用原因，不能为“按钮一直可点”而自动解联锁。
