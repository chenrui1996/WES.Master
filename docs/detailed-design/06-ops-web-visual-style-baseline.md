# Ops Web 工业风格视觉基准

- 状态：规范已批准；当前代码验收证据见[运维客户端实施记录](../implementation/20-t03-t04-operations-client.md)
- 适用范围：Ops Web 当前全部具名路由及后续新增页面
- 权威顺序：业务、权限、物理安全和页面交互合同优先；本文件只规定呈现与可用性，不创建新的操作能力
- 实施基础：Vue 3、Element Plus、语义 HTML 与现有服务端授权投影

## 1. 产品阅读与页面级别

这是供仓储运营人员、调度员及授权维护员高频使用的内部运营控制台。列表和审计默认紧凑，以提高同屏信息量；表单、身份验证和高后果确认保留标准可读性。通常浏览/筛选为低后果，授权、凭据、租户切换和删除按既有安全合同处理，不能因视觉调整而弱化确认、权限或复核。

默认组合：`DENSITY=3`（密集列表）、`DATA_COMPLEXITY=2`（服务端授权的可筛选/分页表格）、`CONSEQUENCE=3`（高风险操作仍需显式安全门）。

页面依然遵守[页面、功能与详细测试共用规范](00-shared-page-and-test-standard.md)和[密集页面交互补充合同](03-dense-page-interaction-contract.md)。该视觉基准不替代各模块字段、空态、权限、版本、过滤和测试合同。

## 2. 颜色、字体与间距

### 2.1 语义颜色

使用低眩光浅钢灰工作区、白色内容面、石墨导航及安全琥珀主操作。语义色仅表示语义，状态同时提供文字或可访问名称，不能单靠色相表达状态。

| Token | 初始值 | 用途 |
|---|---|---|
| `--wes-color-workspace` | `#EDF1F4` | 工作区背景 |
| `--wes-color-surface` | `#FFFFFF` | 页面、编辑和表格表面 |
| `--wes-color-graphite` | `#29343E` | 导航 |
| `--wes-color-graphite-strong` | `#202A33` | 导航按钮/深层表面 |
| `--wes-color-text` | `#26323C` | 正文 |
| `--wes-color-muted` | `#52616E` | 次级说明 |
| `--wes-color-border` | `#748390` | 控件边界 |
| `--wes-color-border-soft` | `#C8D1D9` | 分隔线、表格边界 |
| `--wes-color-primary` | `#F1B747` | 主操作与当前导航 |
| `--wes-color-primary-ink` | `#27313A` | 琥珀表面的文字 |
| `--wes-color-focus` | `#005EA8` | 键盘焦点 |
| `--wes-color-danger` | `#B42318` | 危险/错误 |
| `--wes-color-warning` | `#805400` | 警告 |
| `--wes-color-success` | `#176B3A` | 已确认成功 |

这些值是基线初值，不是对比度通过声明。任何修改必须针对最终前景、背景、焦点环和控件边界组合实测 WCAG 2.2 AA。琥珀背景使用深色前景；不默认采用白色主操作文字。禁止渐变、闪烁和颜色编码唯一状态。

### 2.2 排版

- 使用 Windows/中文系统字体栈，不加载远程字体。
- 正文和表单说明约 14px，行高 1.45–1.5；表格正文约 13px。
- 页面标题约 20px，段落标题约 16px；不得用大标题挤占业务工作区。
- 表单输入字体至少 16px，避免移动 Safari 聚焦时意外放大。
- 标识、哈希和无空格长值换行或提供可访问的完整值展开；不得截断主标识、标题、错误或按钮文字。

### 2.3 间距与轮廓

间距采用 4px 节奏：4、8、12、16、24、32px；控件圆角约 4px。颜色、字号、间距、边界和密度均由 `clients/ops-web/src/style.css` 的 `--wes-*` token 驱动。组件不得引入重复的页面级颜色值或全局远程字体。

## 3. 应用框架与响应式规则

- 顶栏基准高约 56px，显示环境/现场控制边界；已认证时另显示当前租户、显示密度和退出入口。
- 桌面左导航默认 60px 窄轨，可展开至约 224px。展开按钮具有可访问名称、`aria-expanded` 与 `aria-controls`；折叠项仍保留完整屏幕阅读器名称。菜单按当前授权显示，但服务端仍是权限权威。
- 视口不大于 1024px 时导航转为局部横向滚动条；不允许文档级横向滚动。导航收起状态不影响路由、授权或页面操作。
- 内容容器、表格宿主和工具栏文本子项允许收缩（`min-width: 0`）。宽表仅在自己的 `.table-scroll` 容器内滚动；固定表头受限于同一个表格滚动容器。
- 标题、筛选和主操作优先组合在紧凑页首；筛选控件可换行，不缩到不可用尺寸。危险确认继续使用原有安全语义和焦点顺序。
- 视口不大于 640px 时顶栏和登录面板进一步堆叠；窄屏不声称具备桌面工程操作等价能力。

## 4. 密度与通用页面结构

密度只控制表格行内容留白，不缩放浏览器、不改变字段、排序、过滤、分页、授权或写入语义。

| 模式 | 默认用途 | 目标表格数据行高 | 控件 |
|---|---|---:|---|
| 紧凑 `compact` | 用户、角色、租户、会话、审计等高密度列表 | 36–40px | 不低于 44px |
| 标准 `standard` | 一般读表和表单 | 44–48px | 不低于 44px |
| 舒适 `comfortable` | 用户主动选择的易读模式 | 52–56px | 不低于 44px |

默认密集列表紧凑。表单、登录、详情和高后果确认始终保持标准排版，不继承紧凑行距。所有可点击按钮、选择器、输入框和键盘焦点指示器均保持清晰；复选框的整行文字可点击，目标高度至少 44px。

通用页面骨架使用 `.wes-page`：

1. 紧凑页首：语义标题、可选短说明。
2. 过滤/工具栏：具名表单、显式提交和清除语义。
3. 页面内联状态：读取中、空结果、权限不足、离线、错误、成功分别表达，不将错误伪装为空结果。
4. 列设置和授权字段投影。
5. 局部滚动表格、分页。
6. 标准密度编辑区及显式保存/取消/危险确认。

记录以表格行承载，不为每条数据增加卡片。卡片仅用于独立仪表组件，不用于列表行。审计页保持只读证据语义。登录与会话页沿用同一令牌，但不显示认证后管理导航。

## 5. 密度偏好和隐私

显示密度是本地、非安全性偏好。键包含应用环境、租户 ID 和当前已认证用户 ID；值只能是 `compact`、`standard` 或 `comfortable`。身份令牌、授权、业务行、密码、表单内容和会话状态不得写入该偏好。

- 无主体时使用列表默认紧凑且不访问身份范围存储。
- 登出或主体/租户变化时，先清除当前内存密度和提示，再读取新身份键；不得闪现上一用户偏好。
- 无效值回退紧凑并显示非阻断提示。
- 浏览器禁止读取/写入存储时，页面与控件继续可用；本次会话中选择仍生效，明确提示未持久保存。
- 密度是呈现设置，不是授权信号；隐藏列仍不能作为数据安全边界。

## 6. 无障碍、状态与安全边界

- 正文、焦点指示器、控件边界与语义状态满足 WCAG 2.2 AA；使用 `:focus-visible` 并完整支持键盘导航。
- 200% 浏览器缩放和长中英文标识下，标题、标签、错误信息和操作仍可阅读和访问；不得靠固定文本宽度剪裁。
- 关键触控/操作目标不小于 44px；紧凑表格行不代表控件可以缩小。
- `prefers-reduced-motion: reduce` 时关闭非必要动画与过渡；状态含义不依赖动画。
- 页面级、区域级和字段级的加载、空、错误、无权、只读、离线与陈旧状态仍遵守对应模块测试合同；视觉样式不能改变服务端owner查询、幂等、版本冲突或物理控制门禁。
- 按钮只展示现有能力；不因折叠、窄屏、密度或主题状态隐藏授权操作。

## 7. 实现和验收

共享 token、shell 和页面类位于 `clients/ops-web/src/style.css`；导航与密度控件位于 `clients/ops-web/src/App.vue`；偏好实现位于 `clients/ops-web/src/features/visual-preferences.ts`。页面通过 `.wes-page` 加入基准并保留原本的 API 和状态逻辑。

接受新的页面或改版前，至少验证：

1. 1440px 桌面默认窄轨、展开状态和当前授权菜单。
2. 1024px、768px 与 375px 的文档无横向溢出；宽表仅在本地滚动。
3. 三档表格行高及至少 44px 的交互目标；表单/确认不随密度缩小。
4. 环境/租户/用户偏好隔离、无效值、存储不可用、身份切换及登出清理。
5. 键盘可达、清晰焦点、状态文字、减少动态效果和最终色彩对比度。
6. 200% 实际浏览器缩放、中文/英文长文本、空态/错误态及真实 HTTPS 浏览器工作流。
7. 现有组件测试、严格 TypeScript 构建和受控集成测试通过；不将 UI 测试冒充现场或物理验收。
