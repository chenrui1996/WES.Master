## 1. 页面/焦点与字段

| PAGE定义 | 角色/入口 | 单列文本线框/字段/验证 | 动作/返回 |
|---|---|---|---|
| PAGE-PDA-001 | 操作员；`/pda/login`→`/pda/tasks` | 环境/在线 → 登录 → 权限菜单/任务列表。账号/凭据按Platform；仓库/班组上下文、任务业务号/类型/状态/缓存时间；禁止客户端切伪租户 | 按任务类型/业务号/本人班组，默认25；扫码选任务；后退保留过滤，不保留凭据；登录失效回授权站内页 |
| PAGE-PDA-002 | 收货员；`/pda/receiving/:task` | 单号/剩余 → 订单/容器/物料扫描区 → 数量+单位 → 收货位 → 确认 → 回执。扫描值类型/归属/剩余由WMS校验；手输仅策略允许 | 一次仅当前扫码目标聚焦；提交后显示operation；数量不取扫码次数直接无限累加；成功后由回执决定下一行 |
| PAGE-PDA-003 | 上架员；`/pda/putaway/:task` | 容器 → 来源/建议目标 → 扫目标 → 影响预览 → 在线确认。源/目标/Pack/容器/版本；目标非禁用/冲突位 | 错码保留任务、聚焦错误输入；确认后显示待运输或人工确认结果，不将已申请显示已到位 |
| PAGE-PDA-004 | 拣选员；`/pda/picking/:task` | 任务/剩余 → 源位/容器/物料扫描 → 实拣/单位/短缺原因 → 确认拣选 | 快速重复扫描受去抖但服务端仍幂等；短缺保留计划/剩余；不出现普通“强制完成” |
| PAGE-PDA-005 | 盘点员；`/pda/counts/:task` | 计划/局部锁→扫位/料/容器→默认盲盘仅实盘→提交计数→待复核；非盲盘须显式授权策略 | 实盘≥0；默认不返回账面/差异，修订留痕，盘点人禁自批；人工解锁后旧计数失效重盘；返回可保留在线内存输入，断网不持久保存待写 |
| PAGE-PDA-006 | 发运员/异常报告员；`/pda/shipping/:task` | 单据/运输检查 → 容器/位置扫描 → 发运确认；异常分支：来源/位置/描述 → 报告回执 | 只有无未完成WCS物理动作才可合法直发；异常报告不含设备控制；高危处置引导授权地图入口 |

```text
当前应扫描：容器（清楚的字段标签）
[扫描值]  校验结果
数量 [      ] 单位 [只读]
[确认收货/拣选/计数/发运]
操作记录：处理中 / 结果未知请查询 / 确认结果
```

状态适用：001适用UI-001..004/007..009/011；002..006适用UI-001/003..010/012。无桌面宽表/批量控制，UI-011跨页选择不适用002..006；任务不存在不引导新建。独立扫码字段错误不清其他已验证字段；离线只读显示数据时间/过期，输入中的业务写数据不进入本地持久队列。

## 2. 功能

| FUNC定义 | PAGE/REQ/原TC | 编号规则与契约 |
|---|---|---|
| FUNC-PDA-001 | 001；REQ-PDA-001..006；PDA-TC-001..002/013..015 | 1Platform登录/授权菜单；2server过滤任务；3用户/仓/租户切换清缓存/选择；4过期重新认证。不以菜单隐藏作为授权 |
| FUNC-PDA-002 | 002/003；REQ-PDA-001..006；PDA-TC-002..005 | 1读取最新任务版本；2按扫描字段校验物料/容器/位置/数量/单位；3唯一key在线提交WMS；4查operation回执；5上架需运输时等待真实完成。不自行扣账或建Pack内部任务 |
| FUNC-PDA-003 | 004；REQ-PDA-001..006；PDA-TC-006 | 1任务/预留有效性核验；2扫描来源与物料；3确认实拣/短缺；4WMS按任务类型推进。重复请求同结果，错/取消任务不消费预留 |
| FUNC-PDA-004 | 005；REQ-PDA-001..006；PDA-TC-007 | 1授权计划/盲盘显示；2实时在线录数；3WMS持久计数与修订；4授权审批人另行调账。计数回执不等于库存已调整 |
| FUNC-PDA-005 | 006；REQ-PDA-007..010；PDA-TC-011..012 | 1查发运/物理前提；2在线WMS发运；3异常仅报告来源/证据并关联运维。无强完/解除联锁/真机重发能力 |
| FUNC-PDA-006 | 全页；REQ-PDA-007..010；PDA-TC-008..010/013..015 | 1监听连接但不单靠“网络在线”判业务可用；2断网阻止写/标Stale；3只显示许可缓存至有效期；4重连先查最新任务/operation，绝不重放待提交写。响应超时可留operationID用于查询，但不能把它当自动重放任务 |

扫码适配区分硬件键盘输入/相机输入、扫描终止符与焦点，所有码为不可信string；服务器校验仓库/Pack/schema/任务关联。允许手输时同一校验链。提交期间不重复触发；网络在线但API不可达按结果未知处理，不能把本地按钮回显当确认。

已批准[规则基线RULE-09/PAR-01/03](05-approved-rules-and-defaults.md)：默认键盘楔入+Enter、禁手输，显式授权才开放；持久业务缓存默认关闭，获批且有安全存储证据后只读TTL5分钟，无活动5分钟锁定。operationID例外受保护保存仅为查询，不含待写payload。盲盘/部分收发/短拣共用WMS已定规则，VAL-01/02/04/05纳入既有DTC必测；具体终端仍须H证据。

### 3.1 紧凑页面与关联配置

遵循[交互合同](03-dense-page-interaction-contract.md)，数字为PAGE-PDA；P/S为共用详细测试适用，`!`是当前任务必须持续可见的字段而非桌面固定列。全PDA无列拖动/显隐、桌面个人视图或全结果批量动作；关联信息单列展开，保留扫码焦点。

## 4. 阻断

扫描/手输、缓存期限和锁定初值已按规则基线定案；实际OS/UniApp端/终端型号、安全存储/清除、班组授权和现场网络仍需H证据，无安全存储则保持持久业务缓存禁用。丢失端先撤销会话，远程擦除不能假定支持。Web不能代替扫码枪实机测试，旧TC语义与参数变体均保留。
