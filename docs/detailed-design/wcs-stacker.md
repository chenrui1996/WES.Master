## 2. 功能

| FUNC定义 | PAGE/原TC | 处理/契约/不变量 |
|---|---|---|
| FUNC-STK-001 | 001/002；STK-TC-001..005/008 | 1校验Leg/Pack/请求点/仓库；2排除禁用/锁巷/阈值不足；3稳定权重/轮转选巷与合法双深位；4以任务owner原子持久预约并回SUDR。WMS位置/库存状态经契约核验，业务位置预约仍归WMS、Pack交通/分配claim不伪装同一跨模块事务；协同失败留可恢复申请 |
| FUNC-STK-002 | 003；STK-TC-006..007/015 | 1深位检索查浅位挡货；2建立独立移位引用与同巷合法目标；3先执行/回读移位并向WMS确认；4重新核实后恢复原检索。无安全目标/移位失败/未知容器不跳过阻挡，不改优先级冒充完成 |
| FUNC-STK-003 | 001/003；STK-TC-009..013 | 1固定任务map/deployment；2候选规划并按ExeStack切段；3ledger原子grant后派当前段；4核验device/task/segment/sequence反馈；5离开证据后释放，再推进。反馈重复无新效果，乱序隔离；缓存不作授权 |
| FUNC-STK-004 | 001/003；STK-TC-013..014 | 1运维申请授权/理由/版本/复核；2本包校验设备能力/模式/联锁/epoch/grant；3持久command后语义下发；4超时Unknown并查询；5回读/物理核验恢复。不能从PDA或诊断面板绕过控制链，强制完成不代替真实库存 |

分配契约带requestId/LegId/PackId、源/目标、容器、位置schema、期望版本；反馈带command/task/segment/device/map/sequence。变目标保留旧新引用与原因；旧预约取消/释放和新预约必须按owner工作流恢复，不能因UI改了目的点就释放旧物理占用。
