## 1. 页面/字段/权限

业务数据均由WMS拥有；运输状态从Orchestration查询；Pack路网/设备只读关联。库存/预留不因前端刷新或本地状态改变。

| PAGE定义 | 角色/入口/返回 | 文本线框与核心字段/校验 | 列表/动作 |
|---|---|---|---|
| PAGE-WMS-001 | 主数据管理员；`/wms/locations` | L+F：仓/区/层/巷树 → 货位表 → 绑定/锁原因详情。仓库/位置代码、层巷、Pack、location schema、运营状态、容器；code租户内唯一、父子归属一致，Pack schema校验，不允许任意改已占位归属 | 仓/Pack/锁定/占用/预约过滤；新建/编辑/禁用按活动任务检查；容器位置冲突拒绝；关联地图 |
| PAGE-WMS-002 | 库存查看员；`/wms/inventory` | L+O：维度过滤 → Qty/Available/Reserved → 流水/预留/单据。物料、单位、批次（启用时）、仓位、容器、实物量/可用量、版本/更新时间；数量精确不缩写，null不是0 | 精确容器/物料/库位，批次与时间过滤；禁止直接编辑余额；差异走盘点/授权调整用例；返回恢复过滤 |
| PAGE-WMS-003 | 收货/审核员；`/wms/inbound`及`/:id` | L+F：单头/状态 → 计划行 → 收货记录 → 分配/运输 → 回执。单号/来源、仓库、物料、计划数、实收/待收、单位、容器、收货位/目标、版本；数量>0且单位一致 | 按单号/状态/仓/时间；草稿保存、审核、收货、目标分配/组盘、按状态取消；不得把收货成功等于目标到位 |
| PAGE-WMS-004 | 出库/审核员；`/wms/outbound`及`/:id` | L+F：单头 → 行计划/预留/实拣/已发 → 拣选/运输 → 差异。来源位/容器、必要目标、组/优先、计划与剩余数量、运输分支/引用；精度依物料单位 | 审核/预留、取消申请、进入拣选/发运；行级不足/短拣原因；运输未确认不能直接手工扣账 |
| PAGE-WMS-005 | 拣选/发运员；`/wms/picking` | L+F：待拣任务 → 扫码/数量 → 拣选回执 → 待发运/运输。task、orderLine、reservation、来源/容器/物料、计划/实拣/短缺、原因、版本；server验证任务关联 | 本人/班组/仓/状态过滤；在线确认、短拣报告、合法直发；按钮明确“确认拣选”或“确认发运”，不共用“完成” |
| PAGE-WMS-006 | 盘点员/差异审批人分权；`/wms/counts` | L+F：计划范围/锁 → 应盘行 → 实盘/差异 → 复核/调整流水。快照版本/时间、位置/物料/容器、账面/实盘、计数修订、差异原因；盲盘按策略隐藏账面，实盘≥0 | 建计划/录数/授权确认差异；按计划/未盘/差异过滤；旧快照和在途任务阻断必须可见 |
| PAGE-WMS-007 | 移库员/扩展单据用户；`/wms/transfers` | L+F：TransferOrder单头 → 多行源/目标/数量 → 预留 → 人工确认或运输 → 流水。源≠目标、同合法仓/租户/位置schema、容器/单位/版本 | 草稿/审核/执行/完成/取消；筛选业务号/状态/运输引用；整单与各行一致，不提供未立项拆合托/补货按钮 |
| PAGE-WMS-008 | 库存审计员；`/wms/ledger` | O：时间/维度 → 不可变流水 → 来源单据/运输/补偿。entryID、原因、方向、精确数/单位、前后余额、sourceRef、correlation、occurred时间；稳定时间升序 | 物料/位/容器/来源查询、授权导出；不编辑/删除流水；可跳原单或补偿关联，返回保留条件 |

文本线框：

```text
仓库/业务单号/状态/时间过滤
单据头（版本、审核/执行/同步状态）
行：计划 | 已收/已拣 | 预留 | 运输中 | 已到位/已发
选中行详情：容器/位置/操作记录/错误
业务动作区（按权限/状态） | 流水与运输证据链接
```

状态矩阵：001/003..007适用UI-001..012；002/008适用UI-001..004/007/008/011/012，无普通业务写所以不适用UI-005/006/009/010（导出除外）。单据不存在是未找到/拒绝不是first-empty；首次空主数据可引导管理员，普通操作员无创建权限不引导；无待拣是zero-work。UI-010库存动作不需要假物理回读，但有WCS运输的终态必须按实际证据。

## 2. 功能/契约

| FUNC定义 | PAGE/REQ/原TC | 编号主流程、状态和拒绝 |
|---|---|---|
| FUNC-WMS-001 | 001/002；REQ-WMS-001..004；WMS-TC-002/011 | 1验证组织/仓库/Pack schema；2检查唯一代码与父子归属；3检查占用/预约/锁/活动任务；4版本化更新或拒绝。位置业务占位与容器归属在WMS事务内，禁位不能解除实际占用 |
| FUNC-WMS-002 | 003；REQ-WMS-012..014；WMS-TC-001..004/015 | 1草稿校验全部行；2审核；3扫码实际收货，原子写收入/位置/容器/实收；4同址明确无运输分支，异址建唯一运输意图；5有效到达回调后移源到目标并完成。收货成功后分配失败保留源位实际事实，不回滚已真实收货 |
| FUNC-WMS-003 | 004；REQ-WMS-015..019；WMS-TC-005..006/009 | 1审核按全部行校验可用；2原子预留，绑定订单行；3创建拣选/运输意图；4取消未执行释放未消费预留；5执行中先安全取消/对账再补偿。Draft→Approved/Executing→Completed为原建议基线，未决业务枚举实现前签核 |
| FUNC-WMS-004 | 005/004；REQ-WMS-015..019；WMS-TC-007..010 | 1核任务/容器/物料/来源/版本；2记录实拣/短缺及原因；3按分支：仅确认拣选、合法直发、或等待运输；4发运事务消耗Qty与相应预留。短拣不改计划/整单完成，已挂运输不能直发二次扣账 |
| FUNC-WMS-005 | 006；REQ-WMS-020..023；WMS-TC-012..013 | 1建计划记录范围/快照/锁；2录实盘并保留修订；3检查所有应盘/差异授权/库存版本；4同WMS事务写正负调整流水与结果。过期快照必须重数/核对；不覆盖历史余额 |
| FUNC-WMS-006 | 007；REQ-WMS-024..026；WMS-TC-014/016/018..020 | 1TransferOrder Draft检查多行；2全行审核预留；3人工/WCS分支明确；4每行核预留/运输/版本后原子移动并完成；5取消/失败经可恢复补偿，不删历史。扩展hook仅通过稳定WMS契约，失败不能留下Completed但半数移动 |
| FUNC-WMS-007 | 002/008/全部；REQ-WMS-005..011；WMS-TC-011/015..017 | 1受权维度查询；2以不可变流水解释余额；3重复业务命令/完成回调按业务键去重；4发现不符保持异常并关联运维问题。WCS状态不自动等同库存事实，跨模块无ACID |

请求语义：document/line/task、tenant/warehouse、item/container/location、qty/unit、expectedVersion、operationID/idempotencyKey；运输完成必须匹配transport/Leg、预期源/目标、容器/数量/状态。响应包含接受/处理中/确定结果与可查operation。数量和位置记账在WMS本地事务，外部运输/通知依Outbox与补偿；任何图形拖动/页面改字段不能直接触发账本移动。

## 4. 未决规则

批次/序列号/效期、单位换算/精度、超收/部分收发、短拣后剩余预留、取消边界/交接记账时点、盘点锁与并发方案、预留过期需业务签核。页面显示能力必须按已批准策略启用；不以本测试数量作为生产限额。实现先账本/预留真实Provider测试，再接运输幂等和页面，避免先做可随意编辑余额的CRUD。
