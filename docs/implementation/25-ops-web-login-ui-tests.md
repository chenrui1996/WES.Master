## 1. 用例与验收

| 用例 | 操作/场景 | 预期 |
|---|---|---|
| LOGIN-UI-01 | 空登录页加载 | 租户、账号、密码均可见且标签可访问；访问边界说明真实，不出现已认证的管理导航 |
| LOGIN-UI-02 | 密码字段输入后切换“显示密码”/“隐藏密码” | `type` 在password/text间切换，aria-label与aria-pressed同步，原始空格/字符不改变 |
| LOGIN-UI-03 | 显示后提交有效凭据 | 请求体仍包含用户输入的原密码值；token仅保留在内存，后续身份读取失败仍清理部分会话 |
| LOGIN-UI-04 | 错误响应 | 错误仍通过role=alert显示，关联表单说明；可安全重试，不写入浏览器持久存储 |
| LOGIN-UI-05 | 1440、768、375 CSS px视口 | 桌面双栏、窄屏单栏；文档无横向溢出；全部输入和按钮高至少44px |
| LOGIN-UI-06 | 触屏/窄屏验证码和辅助说明 | 图片不超出表单宽度，文字允许换行，主操作全宽且无被裁剪的标签/错误 |
