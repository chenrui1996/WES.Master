# T06共享查询状态与模块catalog首片实施记录

- 状态：前端首片已实现；T06及其授权查询快照合同未完成
- 依据：[T06工作包](../superpowers/plans/2026-10-23-wes-development-work-packages.md)、[部署功能开关设计](../detailed-design/feature-switches.md)

## 范围

- 新增共享`QueryState`组件，统一呈现loading、error、empty、stale与ready；错误、状态和busy信息提供ARIA语义，stale状态保留默认slot并允许显式重试。
- Audit、用户、角色、租户查询在相同筛选/分页和身份授权范围内刷新时保留最后成功结果；筛选或身份/权限范围变化时清除旧结果，避免跨范围数据闪现。
- 用户目录复用共享状态；相同授权身份、筛选和分页下刷新失败保留上次成功结果并标记stale，筛选变化立即清除旧结果。数据正在刷新或刷新失败时禁用基于旧版本的行操作。
- 角色和租户目录同样在刷新期间显示stale快照；失败时保留结果并禁止使用旧版本编辑、租户切换等行操作。scope/筛选变化立即清空旧数据。
- 强类型配置与字典目录复用查询状态：在相同身份授权、配置类别/字典分类语言及页码下刷新失败保留stale结果；筛选变化清空旧行；配置权限拒绝会丢弃旧数据，不以stale方式继续展示。
- 会话列表刷新复用共享状态；同主体/授权、模式、筛选和页码下失败保留stale快照，并在刷新及stale期间禁用撤销；筛选、模式或身份授权变化仍清除旧行，身份/授权拒绝不保留受限会话。
- 所有现有`useColumns`调用点将列偏好限定于环境/租户/用户/page/table键，仅读写列ID、格式版本、100–600像素的已授权列宽和固定首列布尔偏好；列宽依身份/状态/数值/时间/说明字段采用200/120/120/200/240像素基准、160/100/100/180/180像素最小值，留空恢复基准宽度。首个必显主标识默认左固定。授权操作表的操作列右固定；窄视口由容器宽度查询自动停用水平固定并显示中性提示。从当前授权列schema重新规范化，必显列恢复、撤权列及其宽度移除。损坏/不支持格式或浏览器存储异常通过可访问提示显式呈现，不保存行数据、权限或写入草稿。
- 跨标签收到同一偏好键变化时显示提示，但不自动覆盖当前标签的内存配置；提示引导用户重新载入并确认，避免后台静默改变正在使用的列布局。
- 新增严格的Ops Web模块catalog客户端，只接受服务器规定的六个模块代码及完整、无重复的响应；网络、HTTP、JSON或结构错误均显示明确错误且不创建空/默认全开catalog。重试会重新读取。
- 平台导航要求模块已启用且当前身份具有既有页面权限。Platform直达路由先检查catalog/模块，再执行权限路由守卫；模块关闭或catalog不可用时进入明确状态页。登录和会话路由不受UI模块开关限制。
- 此客户端开关只控制入口可见性/导航；后端API认证授权不变。目录保留在组件内存，不持久化。

## 回退

可回退本片前端组件、导航与路由改动，无需数据库迁移或后端回滚；既有匿名catalog endpoint不依赖本客户端。不得以UI入口隐藏替代服务端授权。

## 本轮列宽/固定列切片

- `ColumnSettings`为当前可读、已显示列提供字段类别宽度输入；最小值为100/160/180像素（依类别），最大值600像素，留空恢复类别基准宽度。授权schema过滤旧范围宽度，越界时显示提示。
- 列设置的显隐、顺序、宽度、固定首列和其他列的左/中/右固定位置均先写入草稿；“应用”后才更新表格及本地偏好，“取消”丢弃草稿，“恢复默认列”只重置列配置，不改筛选或业务数据。
- 未保存首列偏好时默认左固定首个必显标识列；其他列可独立设置固定在左侧、中央不固定或右侧，固定偏好跟随当前环境/租户/用户/page/table隔离。固定列与操作列宽度纳入当前表格框预算；可选固定列不得使总宽度超过容器一半，超限时按可用预算保留符合限制的可选列并提示。若必需标识列和操作列本身已超预算，则不再固定其他可选列并提示转详情查看。
- `useColumns`在原有身份/租户/page/table偏好key下兼容旧版仅列ID格式，并校验宽度结构及上下界；列撤权同步移除对应宽度偏好。
- 修复固定首列偏好的读取遗漏：受支持的`fixedFirstColumn`字段在加载时保留，重载后仍恢复已应用状态。
- 兼容上一轮已保存的最高800像素列宽：读入时逐列按新合同基准校验并仅丢弃越界宽度，保留同一偏好中的列顺序及其他设置并显示提示。
- Audit、Users、Roles、Tenants、Settings/Dictionary及Sessions表格消费共享宽度和固定区布局，左/右吸附偏移依可见列顺序和宽度累计；Sessions、Users、Roles、Tenants、Settings/Dictionary将操作列固定在最右侧并纳入预算。
- 运维Web基准字体使用可随用户默认字号缩放的rem；720px及以下表格视口停用水平固定并显示横向滚动提示，操作列宽度约束为10rem。受控浏览器已验证1600px、375px、表格内容区721/720px精确边界、720px CSS视口/DPR 2 emulation及200%根字号。
- 受控HTTPS Chromium已验证配置表在1600px视口将“稳定键”固定于右侧、偏移160px并保留固定操作列；表格内容区721px时必需标识列保持左固定且提示隐藏，720px时同一列吸附取消并显示提示；375px视口显示固定列停用提示。200%根字号下正文/标题实测28/40px，标题文本另注入+40%长度压力值；表格保持容器内滚动且页面无根级横向溢出。720px CSS视口/DPR 2 emulation覆盖有效视口相当于1440px显示器200%缩放时的窄布局。CDP与根字号仿真均不代表真实浏览器UI缩放或完整本地化验收。
- 所有列设置入口提供作用域隔离的本机个人布局视图：默认布局独立保存且不可删除；个人视图支持另存、覆盖保存、重命名、恢复和确认删除。切换/恢复/删除未保存的个人视图工作副本前会确认；刷新回到默认布局，未保存命名视图修改不会自动写入。持久化白名单包含列ID、授权列宽、固定首列、其他列固定位置、当前授权schema及个人视图名称，不保存筛选、搜索、行数据、选择或待写内容；账号、租户、page、table仍使用现有偏好作用域。
- 当前视图合同只实现列布局，不保存排序或筛选条件；页面尚无可共享的类型化非敏感筛选schema，故不以自由文本/URL内容补齐。存储不可用时保留当前会话操作并明确报错，不伪装为持久化成功。
- `ModuleCatalog`默认请求使用绑定到`globalThis`的`fetch`，避免浏览器在模块导航守卫中以错误接收者调用原生fetch。

浏览器宽/窄视口切片已验证，包含表格内容区720px精确停用边界、720px CSS视口/DPR 2 emulation及200%根字号/+40%合成标题长度；真实浏览器UI缩放、真实长文本本地化和完整覆盖矩阵仍未完成。后端授权快照及个人视图中筛选/排序白名单支持仍未完成。
