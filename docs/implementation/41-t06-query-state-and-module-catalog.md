# T06共享查询状态与模块catalog首片实施记录

- 状态：前端首片已实现；T06及其授权查询快照合同未完成
- 依据：[T06工作包](../superpowers/plans/2026-10-23-wes-development-work-packages.md)、[部署功能开关设计](../detailed-design/feature-switches.md)

## 范围

- 新增共享`QueryState`组件，统一呈现loading、error、empty、stale与ready；错误、状态和busy信息提供ARIA语义，stale状态保留默认slot并允许显式重试。
- Audit查询在相同筛选与身份范围内刷新时保留最后成功结果；筛选或身份/权限范围变化时清除旧结果，避免跨范围数据闪现。
- 用户目录复用共享状态；相同授权身份、筛选和分页下刷新失败保留上次成功结果并标记stale，筛选变化立即清除旧结果。数据正在刷新或刷新失败时禁用基于旧版本的行操作。
- 所有现有`useColumns`调用点将列偏好限定于环境/租户/用户/page/table键，仅读写列ID和格式版本；从当前授权列schema重新规范化，必显列恢复、撤权列移除。损坏/不支持格式或浏览器存储异常通过可访问提示显式呈现，不保存行数据、权限或写入草稿。
- 新增严格的Ops Web模块catalog客户端，只接受服务器规定的六个模块代码及完整、无重复的响应；网络、HTTP、JSON或结构错误均显示明确错误且不创建空/默认全开catalog。重试会重新读取。
- 平台导航要求模块已启用且当前身份具有既有页面权限。Platform直达路由先检查catalog/模块，再执行权限路由守卫；模块关闭或catalog不可用时进入明确状态页。登录和会话路由不受UI模块开关限制。
- 此客户端开关只控制入口可见性/导航；后端API认证授权不变。目录保留在组件内存，不持久化。

## 回退

可回退本片前端组件、导航与路由改动，无需数据库迁移或后端回滚；既有匿名catalog endpoint不依赖本客户端。不得以UI入口隐藏替代服务端授权。
