## 实现

现有审计与登录事件页默认每页 25 条，提供 25/50/100 选择；切换每页条数回到第一页并读取。分页导航具有独立可访问名称，显示当前页、本页行数与每页上限，不伪造总数。整页结果仅表示可能还有下一页；若下一页为空，仍可返回上一页。

页面明确提示实时 offset 在数据变化时不保证跨请求无丢重，不声称固定快照。审计和登录证据为 append-only，测试以新增历史事实演示 offset 位移，不为测试开放修改/删除历史的业务入口。

每次读取捕获独立的请求序号、AbortSignal、证据类型和完整查询指纹。只有查询指纹一致的最后成功页可以作为刷新期间/失败后的 stale 证据保留；翻页、页大小、筛选或身份权限变化均不能继续显示旧页。筛选变更同步取消旧请求、结束 busy 并回到第一页；晚到成功或失败均不得覆盖新查询。

HTTP 401/403 和显式 `authorized=false` 不是可保留数据的暂时故障，必须清空旧证据；响应行数超过请求上限也显式报错。相同 scope 的暂时读取失败仍保留上次证据并明确标为 stale。失败时禁止继续向后翻页，允许重试当前 offset 或返回上一页。

## 验证与边界

受控 HTTPS Host 使用独立租户和共同 correlation 的 60 条合成审计事实；浏览器执行 25+25+10 翻页、60 个不同 ID、50/100 切换回首屏，以及 375/768/1024/1440 布局。当前权限、投影和 offset 位移另由真实 MySQL 测试验证。

本片不增加导出、批量历史操作、快照 token、快照数据存储或跨 owner 查询。其余目录的分页基准尚待统一；600 秒固定快照、动态可修改数据集及完整 DTC-UI-011 仍未验收。现有 QueryScope 值对象未被冒充为授权/TTL 实现。
