## 实现范围

新增具名复用组件 `RealtimePager`，仅呈现与发出分页请求，不拥有数据、权限、业务选择或查询 API。接入审计/登录证据、用户、角色、租户、强类型配置、字典与会话。沿用现有语义 HTML、Vue Composition API 和视觉 token，不引入另一套 Grid 或页面生成器。

所有调用点默认 25 条，只提供 25/50/100 三个页面选项；更改大小回到 offset=0 并读取。服务端既有 1–100 参数兼容不变；会话页不再提供任意 1–100 的数字输入，以符合共用客户端基准。关联候选的独立 50 条批次合同不受影响。

组件提供独立命名的分页 nav、正确关联且不冲突的 select ID、键盘可用的上一页/下一页以及实时状态说明。只显示本页行数和上限，不虚构精确总数；满页只表示可能有下一页。空的后续页仍可返回，字典分页因此从 QueryState 的有数据 slot 移到外部，避免空页时丢失返回入口。

加载或业务写入期间禁用分页与页大小选择；查询失败时禁用继续向后翻页，保留当前范围重试或返回上页。页大小进入各 owner 页面的查询指纹，失败不能把旧大小的数据当作当前页 stale 结果。设置和字典分别保存内存分页状态，不互相改变页码或大小；不新增浏览器业务数据持久化。

用户/角色/租户筛选变更立即回首屏，并在查询进行中使旧 request generation 失效、取消请求、结束 loading，防止上一页晚到结果进入新条件。字典筛选变更同步结束本查询的 busy，旧序号不能再覆盖新结果。服务端授权、行版本、幂等写和同 scope 刷新保留行为保持原有边界。

## 验证与回退

六个非审计调用点分别执行 60 行的 25/50/100 与 offset 断言、改变大小后故障不保留旧行；审计沿用此前真实 HTTPS 60 条及单测。三个目录另外覆盖筛选取消晚到请求，字典覆盖空后续页返回。真实浏览器重新执行具名页面、分页、窄屏、密度与版本化业务写验收。

本片无数据库迁移或服务端 API 变更。回退需连同组件和所有调用点一并回退；不得仅删除组件。

## 未完成边界

本组件是实时查询交互，不提供固定水位、600 秒 TTL、授权快照存储、排序或跨页选择。WMS/Route 等尚未接入的页面不能据此标绿；T06 与完整 DTC-UI-011 仍未验收。
