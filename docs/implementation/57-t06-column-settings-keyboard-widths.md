## 实现范围

强化共享 `ColumnSettings` 的组件行为断言：使用方向键可上下移动已选列，在应用之前只变更草稿列表；只有显式应用后才改变真实列顺序。校验 identity 类型列的最小160px和最大600px边界：159/601像素显示明确的原生校验消息且不应用非法宽度，160/600像素可保存并应用。

此切片仅补充组件回归，不改生产逻辑或偏好合同；不把单组件结果视为任一完整 PAGE 已通过。
