## 实施范围

扩展 `useColumns` 组件测试，使用同一个本地存储实例和实际组合式逻辑，在身份、租户和环境变化时分别保存、切换并重新读取列布局。断言偏好只从匹配的作用域恢复，其他作用域保持默认；匹配原作用域时原有布局仍可恢复。存储值只包含当前授权列配置，不包含行值或筛选输入。

本切片仅补足回归覆盖，不改变偏好键格式、业务状态或服务端授权。身份/租户改变仅用于验证本机 UI 偏好作用域，不能替代每次请求的服务端授权复验。
