# T06 列偏好主体、租户与环境隔离测试记录

- 状态：主体、租户和环境偏好作用域的受控组件回归通过；不代表 DTC-UI-015 或 T06 整体通过。
- 关联：[实施记录](61-t06-column-preference-scope-isolation.md)。
- 依据：DTC-UI-015；偏好按环境、租户、主体、页面和子表隔离。

## 验证场景

同一受控存储中，以一个具名页面和授权列 schema，依次切换租户、主体及环境：

1. 主体 U1 在租户 TA 保存布局；切换至 TB 后不得读取 TA 布局，TB 保存后再切回 TA 应恢复 TA 布局。
2. 在 TA 切换至 U2 后不得读取 U1 布局；切回 U1 后应恢复 U1 布局。
3. 在同一主体/租户下切换环境后不得读取另一环境偏好；恢复原环境后应读取原布局。
4. 持久化值仅包含当前授权列布局字段，不包含筛选值、行值、密钥或待写内容。

## 限制

本测试使用 Vue 组件和内存存储替身，不等同于真实浏览器配置文件隔离、跨设备同步或 API 授权验证。列显隐只影响展示，任何数据请求仍由服务端按当前主体授权。

## 可观察断言

- 相同环境、主体但不同租户，不读取或覆盖彼此的已保存列布局。
- 相同环境、租户但不同主体，不读取或覆盖彼此的列布局。
- 相同主体和租户的不同环境互不复用；回到原环境恢复原配置。
- 实测列偏好仅保存版本、授权列ID、宽度及固定首列状态，不保存页面行值。
