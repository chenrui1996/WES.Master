# T06 列偏好授权 schema 变化迁移

- 状态：DTC-UI-016 偏好 schema 变化与授权列白名单回归通过；已修复 schema 更新时旧偏好未规范化写回的问题，不代表完整 DTC-UI-016 或 T06 完成。
- 依据：[密集页面交互合同](../detailed-design/03-dense-page-interaction-contract.md) §2.2、DTC-UI-016。
- 测试记录：[列 schema 迁移测试](66-t06-column-preference-schema-migration-tests.md)。

## 实施范围

扩展列偏好测试，加载旧 schema 下已保存的布局并套用当前授权 schema。验证旧字段（包括曾可见字段与宽度）被移除，新加入字段按当前 schema 默认纳入，重命名只改展示标签而不丢失稳定列 ID 的用户选择和宽度。持久化后的偏好只包含当前授权列。

修复点：先前首次加载发生 schema 变更时，内存布局已规范化，但存储值仍保留撤权列；刷新或稍后重载会继续携带旧字段。现在仅当已记录的 `knownColumns` 与当前 schema 不同时，才将规范化布局写回。正常打开不会因无关列宽校验而改写存储；写回失败仍提示存储不可用并保留当前会话布局。

本切片沿用偏好格式版本及 `knownColumns` 基线，不改变偏好键或授权列来源；不从历史本地数据恢复已撤权列。
