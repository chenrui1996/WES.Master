# T06 恢复默认列的作用域隔离

- 状态：DTC-UI-014 恢复默认列不触碰筛选与业务数据的组件回归切片；不代表完整 DTC-UI-014 或 T06 完成。
- 依据：[密集页面交互合同](../detailed-design/03-dense-page-interaction-contract.md) §2.1、DTC-UI-014。
- 测试记录：[恢复默认列隔离测试](68-t06-column-reset-isolation-tests.md)。

## 实施范围

扩展 `ColumnSettings` 具名组件测试，模拟当前筛选和业务行值与列配置同时存在。用户恢复默认列并显式应用后，仅列显隐、宽度与固定列草稿恢复默认；筛选条件与业务数据必须保持不变。

本切片只增加交互回归，不改变业务筛选、行数据或列默认值。
