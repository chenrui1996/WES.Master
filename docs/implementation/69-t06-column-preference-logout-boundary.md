# T06 列偏好登出内存边界

- 状态：DTC-UI-015 本机列布局与登出内存状态边界回归切片；不代表完整 DTC-UI-015 或 T06 完成。
- 依据：[密集页面交互合同](../detailed-design/03-dense-page-interaction-contract.md) §2.2、DTC-UI-015。
- 测试记录：[登出边界测试](70-t06-column-preference-logout-boundary-tests.md)。

## 实施范围

使用实际 `useColumns` 和身份状态装配验证：登出时身份作用域失效，当前组件不继续显示上一主体的列布局；本机持久化列布局不删除，以便同一主体重新认证后恢复。不同主体偏好继续按独立作用域隔离。

此处只验证列偏好与身份生命周期的边界，不将列布局等同业务行/选择缓存，不宣称该测试覆盖全页行数据和关联候选清理。
