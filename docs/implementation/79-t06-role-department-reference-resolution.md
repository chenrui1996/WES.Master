# T06 角色规则部门引用独立回填

- 状态：DTC-UI-022 Platform Roles 编辑既有规则时的部门引用回填首片；不代表完整 DTC-UI-022 或 T06 完成。
- 依据：[密集页面交互合同](../detailed-design/03-dense-page-interaction-contract.md) §4.1、§4.2.4、§4.2.5、DTC-UI-022；[Platform页面/功能设计](../detailed-design/platform-and-security.md) PAGE-PLAT-004、DTC-PLAT-014。
- 测试记录：[角色部门引用独立回填测试](80-t06-role-department-reference-resolution-tests.md)。

## 实施范围

编辑已有角色时，读取实体与版本后，由 Platform Department owner 对规则中不同的部门 ID 批量解析授权可见代码、名称和启用状态，不依赖首屏或当前候选页。每个请求限制最多 100 个唯一 ID；更大的现有规则集合按有界批次读取。owner 使用可信主体/租户及当前部门 `Id` 字段资源范围，只返回范围内的投影；名称、代码、启用状态仍逐部门检查字段授权。

未返回的引用统一显示“关联不可用或当前无权查看”，不得显示其隐藏名称或通过消息区分不存在与无权。读取失败只影响关联摘要，保留已授权角色规则和版本，不伪装解析成功。已停用部门作为历史规则关联显示状态，不成为新增候选；本切片不改变角色保存策略，保存时仍由角色 owner 复验权限。

## 不在范围内

不扩展其他模块选择器，不实现 Users 页关联回填，不调整角色规则业务语义或写入授权，不声称真实浏览器或完整 DTC/T06 验收。
