# PDA 详细设计

- 状态：目标设计；Seven 有可复用页面/API/服务，页面到设备的完整 E2E 尚待验收
- 范围追踪：`SCOPE-PDA-01`、`SCOPE-PDA-02`、`SCOPE-WMS-03` 至 `SCOPE-WMS-05`
- 前端形态：UniApp + Vue 3 + TypeScript；按 Frontloom Core FE/Vue 通用原则，遵循 UniApp 平台生命周期和设备能力限制

- 测试前缀：`PDA-TC-*`

## 1. 产品目标和在线权威

PDA 面向收货、上架、拣选、盘点和经授权的异常查看/发运操作。所有写操作在线提交给 WES API，由 WMS 验证身份、权限、单据状态、库存和并发版本。PDA 不持有库存权威，不直接写数据库、WCS 表、设备协议或 PLC。

Seven 已有标准菜单含收货/上架/拣选/盘点；当前控制器有 `/api/pda/picking/pending` 与 `/api/pda/picking/confirm`，页面与 WMS 服务测试已证实存在。现有测试主要使用 EF InMemory；这不代替真实 UniApp 终端、API 权限、扫码硬件和数据库并发 E2E。

## 2. 离线行为（已确认）

- 离线时只允许展示经策略允许的只读缓存；**不创建、保存或重放任何待提交写操作**。
- 收货、上架确认、拣选确认、盘点记录/调整、发运、异常处置等都要求实时在线；断线时禁用提交按钮并明确提示。
- 页面显示数据获取时间、在线/离线状态和缓存陈旧标识；超过配置有效期后敏感/可变任务数据隐藏或阻止继续操作。
- 登录令牌和本地缓存按 Platform 安全策略存储；缓存最小化、按用户/租户隔离，登出/账号切换/设备丢失时清除或撤销。
- 恢复联网后重新从服务器拉取状态。此前离线期间没有待提交动作，因此不执行冲突合并或重放。

只读缓存期限、设备加密能力、自动锁定和远程清除能力依终端平台/现场安全要求确定；不能假设所有 UniApp 目标端支持相同安全存储。

## 3. 角色与页面

| 角色 | 允许能力 | 明确禁止 |
|---|---|---|
| 收货操作员 | 查看有权收货任务、扫码确认物料/数量/容器/收货位 | 修改审核单、跳过 WMS 校验 |
| 上架操作员 | 查看待上架容器、扫描目标位并确认 | 指定禁用/错误 Pack 货位或绕过占位状态 |
| 拣选操作员 | 查看本人/班组授权任务、扫描任务/容器/商品并在线确认 | 手工改变预留数量或绕过 WCS 任务状态 |
| 盘点操作员 | 查看盘点计划、记录实时实盘并提交 | 未授权确认差异/调整库存 |
| 发运操作员 | 查看已拣/待发运任务，按业务授权在线确认装车/发运 | 对在途 WCS 任务执行直接扣账 |
| 运维/异常处理人 | 查看异常和处置指引；必要操作跳转至以 2D 监控地图为主入口的 Orchestration/WCS 运维工作台 | 使用普通 PDA 菜单直接强制完成、解除联锁或控制真实设备 |

页面至少包含登录/失效、任务列表/空态、任务详情/扫码、确认结果、业务错误、网络错误、离线只读、缓存过期、权限拒绝和处理中状态。手动输入仅在业务与安全策略允许时提供，必须与扫描值执行同一校验。

## 4. 在线业务流程

### 4.1 收货

获取待收货单 → 扫订单/容器/物料 → 显示计划数量和允许收货位 → 输入/扫描实收数量及收货位 → 服务端校验余量、角色、物料、单位、位置和并发版本 → WMS 原子记收货事实 → 显示回执与明细状态。响应超时不可盲目重提，客户端保留本次请求 ID，重新查询服务端状态后再提供安全重试。

### 4.2 上架

读取待上架容器 → 扫描容器和目标位 → 显示来源、目的、Pack/仓库校验结果 → 在线确认 → WMS 创建人工移库或 Orchestration 运输意图。运输尚未完成时页面明确显示“待运输”，不提示库存已在目标位。

### 4.3 拣选

加载待拣任务 → 扫描任务/容器/物料/来源位 → 核对计划数量和任务状态 → 在线确认 → WMS 更新拣选/出库状态，若需要设备运输则通过统一运输契约发起。`ConfirmPick` 只能对服务端当前仍有效的任务执行；重复扫码/提交不能重复扣账。

当前 Seven 控制器使用 `POST /api/pda/picking/confirm`，页面实现已存在。WES 保留此能力的业务语义，可在 API 版本设计时优化契约，不以 endpoint 名称作为前端硬编码业务规则。

### 4.4 盘点

读取授权盘点计划 → 扫位置/物料 → 展示必要账面信息（根据盲盘策略可隐藏）→ 在线录实盘数 → 服务端检查计划状态和重复/版本 → 显示差异但不擅自调账 → 有权审批人确认后由 WMS 应用调整流水。

### 4.5 发运与立库异常

- 发运页面只为“待发运且无未完成物理/WCS 操作”的任务提供在线确认；调用 WMS 发运用例，不在 PDA 内实现扣账逻辑。
- 发现缺货、错位、堵塞或设备故障时，普通 PDA 用户提交异常报告/现场信息并显示关联单据/位置；异常处置人使用经授权的 2D 地图运维工作台与 Orchestration/WCS 流程。
- 强制完成、任务取消、设备命令、联锁解除不属于普通 PDA 能力。若现场需要受限快捷入口，先独立安全评审、双人授权/确认与审计。

## 5. API、权限和可靠性要求

- 每个查询和写入 API 都以认证主体、角色、租户、数据范围、资源归属和状态机判定为准。
- 请求携带唯一 `Idempotency-Key` 或命令 ID，响应返回可查询的业务操作 ID、最终/处理中状态和安全可展示错误码。
- 扫码值作为不可信输入；服务端验证编码格式、租户/仓库、Pack、任务关联和业务状态，不因客户端已查过而省略。
- 网络超时后使用服务端状态查询；客户端请求重试不能创建第二条库存流水、任务或运输单。
- 并发设备操作用业务版本/ETag 或原子状态转换；冲突提示刷新任务，不覆盖其他操作者结果。
- API 不返回未授权的其他班组/仓库任务，也不在错误消息中泄露客户、库存或设备敏感详情。

## 6. 详细验收用例

| ID | 场景 | 期望 |
|---|---|---|
| PDA-TC-001 | 登录成功、令牌过期、登出、换账号 | 令牌安全处理；换账号后旧任务/缓存清除 |
| PDA-TC-002 | 无 PDA 权限但直接调用菜单/收货/拣选 API | 服务端拒绝且无单据/库存副作用 |
| PDA-TC-003 | 收货正确/超计划/错单/错误物料/重复提交 | 正确收货只记一次；非法/重复行为符合幂等规则 |
| PDA-TC-004 | 扫错容器、目标货位锁定、错误 Pack 前缀 | 具体可操作错误；无移库和占位副作用 |
| PDA-TC-005 | 上架确认成功但运输仍在途 | 页面显示待运输；不误报目标库存已到位 |
| PDA-TC-006 | 拣选 pending/确认成功/重复/并发确认/任务已取消 | 只有当前合法任务可确认；账本和出库状态最多变更一次 |
| PDA-TC-007 | 盘点计划授权、漏扫、重复录数、差异确认越权 | 记录可追溯；未完成或未授权时不产生调账 |
| PDA-TC-008 | 在线提交途中断网、超时后重连 | 禁止新写入；先查询原命令状态，不盲目重复扣账 |
| PDA-TC-009 | 只读缓存离线、缓存过期、租户/用户切换 | 明示离线和陈旧时间；过期数据受限；无跨用户/租户泄漏 |
| PDA-TC-010 | 离线期间尝试收货/拣选/盘点/发运 | 提交控件禁用且 API 不可达/拒绝；不保存、不重放待写操作 |
| PDA-TC-011 | 发运任务已有活动运输或不满足授权 | PDA 不显示可确认或 API 拒绝；无扣账 |
| PDA-TC-012 | 普通操作员尝试设备异常强制完成/联锁解除 | 拒绝并引导 2D 地图优先的 Orchestration/WCS 运维工作台；未经授权无设备命令 |
| PDA-TC-013 | 扫码枪事件重复、无焦点、非法字符、手工输入 | 同一服务端校验路径；界面不会因设备事件重复双提交 |
| PDA-TC-014 | 真实 UniApp H5/目标移动终端端到端验证 | 登录、权限、扫码、离线只读、生命周期和错误状态符合平台实现 |
| PDA-TC-015 | 服务端 API 与数据库并发集成 | 三种 provider 上的账本/幂等/并发规则一致或差异已登记 |

## 7. Seven 基线核验和迁移注意

现有 `PdaServiceTests` 覆盖标准菜单、转入收货/上架、盘点流程；拣选服务测试在 `Wms/PickingServiceTests`，控制器公开 picking pending/confirm。WES 应补充 PDA API 的授权/验证集成测试和真机扫码 E2E，而不是只以页面文件存在宣告闭环完成。

当前 Seven 文档将“PDA 未做拣选”与已有代码冲突；WES 按代码/API/测试证据保留拣选，并将 Seven 文档不一致登记为基线文档债务。发运 PDA 操作与立库异常查看/处置是需新增设计并经业务/安全验收的范围。
